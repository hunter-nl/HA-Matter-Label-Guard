# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please do not disclose vulnerabilities in a public issue. Use GitHub's private
[security advisory reporting](https://github.com/hunter-nl/HA-Matter-Label-Guard/security/advisories/new)
for this repository. Include the affected version, reproduction steps, impact,
and any suggested mitigation.

If private reporting is unavailable, open a public issue only to request a
private contact channel; do not include vulnerability details.
